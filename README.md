# Ателье Флёр — демо-проект

Иммерсивный сайт цветочного ателье: WebGL-сцены S01–S04, 3D-камера, глубина, покадровая прокрутка (один свайп — один кадр). Название вымышлено. Контактов и внешних ссылок на странице нет.

## Запуск локально

Страницу нужно открывать через локальный сервер, а не двойным кликом: браузер не даёт WebGL читать текстуры с `file://`.

```
npx serve .
# или
python3 -m http.server 8080
```

## Публикация на GitHub Pages

1. Положите содержимое этой папки в корень репозитория (или в `/docs`).
2. Settings → Pages → Source: **Deploy from a branch**, ветка `main`, папка `/ (root)` или `/docs`.
3. Через минуту сайт откроется по адресу `https://<user>.github.io/<repo>/`.

## Состав

| Путь | Что это |
|---|---|
| `index.html` | Страница сайта |
| `support.js` | Runtime страницы |
| `vendor/` | three.js 0.160, React 18.3.1 (локальные копии, внешние CDN не нужны) |
| `fonts/` | Cormorant Garamond, Onest, IBM Plex Mono и альтернативы, woff2 + `fonts.css` (лицензия OFL) |
| `assets/images/` | 10 изображений, созданных в Higgsfield, и карта глубины |
| `.nojekyll` | Отключает обработку Jekyll на GitHub Pages |
